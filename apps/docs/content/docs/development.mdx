BugBerry is a Bun monorepo: the API (`apps/api`), the dashboard (`apps/client`), the browser extension (`apps/extension`), these docs (`apps/docs`), and shared packages under `packages/`.

Everything you need to run it locally, test it, and send a change is in [CONTRIBUTING.md](https://github.com/yuisalabs/bugberry/blob/main/CONTRIBUTING.md) in the repository.

Found a bug or want a feature? Open an issue on [GitHub](https://github.com/yuisalabs/bugberry/issues).
