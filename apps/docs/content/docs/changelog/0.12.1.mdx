---
title: 0.12.1
description: Released 4 November 2026.
---

- **No more "Extension context invalidated" after an update.** A tab open from before the extension was updated or
  reloaded kept the old extension's scripts. On a dashboard tab, each return to it put that error on the extension's
  Errors page; an armed tab kept recording its replay. The old scripts now stop on their own, and an open dashboard
  finds the extension again without a refresh. A dashboard tab open since 0.12.0 or earlier can still show the error
  until you refresh it.
- **Self-hosting:** update the extension to 0.12.1. The server and the dashboard stay as they are.
