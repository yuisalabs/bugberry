- **Instant replay: capture the last minute after the bug.** Arm a tab from the popup; when the bug shows, press
  Capture and the last 30, 60 or 120 seconds become a report with a replay of the page, screenshots every 5 seconds,
  and the logs. Chrome and Opera. See [Instant Replay](/guide/recordings#instant-replay).
- **Self-hosting:** update the server, the dashboard and the extension to 0.12.0. Migration `0034` runs when the
  server starts. A replay counts as a recording against the account limits.
