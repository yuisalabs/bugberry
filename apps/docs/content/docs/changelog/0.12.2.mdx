title: 0.12.2
description: Released 10 November 2026.
---

- **Logs from tabs open before the extension.** A tab already open when the extension was installed or updated had no
  capture running, so its reports came without console, network or actions. The extension now starts capturing in
  those tabs as soon as it is installed or updated; what happened before that moment is still missing. Where the
  capture still isn't running, the popup says so and offers **Reload tab** before you capture.
- **Self-hosting:** update the extension to 0.12.2. The server and the dashboard stay as they are.
