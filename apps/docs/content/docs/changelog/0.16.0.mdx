- **Request links.** Send a link to someone without an account or the extension: they record their screen or take a
  screenshot in a desktop browser, and it arrives as a report filed in your name, marked **Sent by** them. You hear
  about it in the bell and by email, and it waits for you before going to any tracker. See
  [Request Links](/guide/request-links).
- **A project guest who is also a member elsewhere:** while the guest workspace is open in the dashboard, an AI agent
  that names no workspace works in the one you last opened as a member, not the oldest one you joined.
- **Self-hosting:** the server adds migrations `0040` (the `recording_request` table and three report columns) and
  `0041` (the workspace each person last opened as a member) when it starts. With S3 storage, the bucket's CORS rule
  must allow `PUT` from `APP_URL`; the shipped `deploy/bucket-cors.json` already does, but an older bucket may allow
  only `GET`. The extension stays at 0.13.2; it only takes two helpers from a shared package.
- **Self-hosting:** with local storage, file links send `X-Content-Type-Options: nosniff`.
