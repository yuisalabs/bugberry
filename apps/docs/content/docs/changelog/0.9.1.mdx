- **AI agents can watch a recording.** Before, an agent only got a video report's thumbnail. The new MCP tool
  `getRecording` gives it a link to the video, valid for 5 minutes. It also lists up to 20 moments worth a frame, in
  video time: errors and failed requests with the click just before them, your notes, rage clicks, and page changes.
  It comes with the `ffmpeg` commands to cut those frames. An agent on your computer, such as Claude Code, Cursor, or
  VS Code, downloads the video, looks at the frames next to the console and network logs, then deletes them. For a
  video report, `getReport` now suggests `getRecording` as a next step, and the report's activity shows "read the
  recording". See [AI Agents](/guide/ai-agents#recordings).
- **Self-hosting:** update the server. There is no migration and nothing to set. The extension stays at 0.9.0.
