- **BugBerry for Firefox goes to Firefox Add-ons.** This is the first version sent to the public listing. Once Mozilla
  has reviewed it, Firefox installs BugBerry from there and keeps it up to date. A copy installed from a `.xpi` file
  updates to it by itself.
- **Self-hosting:** nothing changes on the server. Nothing changed on Chrome either, so it stays at 0.9.3.
