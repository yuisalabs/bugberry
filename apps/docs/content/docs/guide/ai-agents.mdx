title: AI agents (MCP)
description: Let Claude, Cursor, VS Code, ChatGPT, and other AI apps read and work on reports.
---

BugBerry has an MCP server, so AI apps can read reports and work on them. It works with Claude Code, Claude.ai, Codex, Cursor, VS Code, Windsurf, and ChatGPT.

## Set it up

Open **AI Agents** in the dashboard's top bar. The page has copy-paste setup for each app. The MCP address is `<your BugBerry address>/api/mcp`.

<Screenshot src="/screenshots/ai-agents/mcp.png" alt="The AI Agents (MCP) page: Connect an app in three steps, with tabs for Claude Code, Claude.ai, Cursor, VS Code, Windsurf and ChatGPT; Personal tokens and Connected apps on the right" />

For Codex, run both lines in a terminal; the second opens BugBerry in your browser to sign in:

```bash
codex mcp add bugberry --url https://bugberry.example.com/api/mcp
codex mcp login bugberry
```

Most apps sign in with OAuth: the app opens a BugBerry page where you approve it. For apps without OAuth, create a **personal token** on the same page; the app sends it as `Authorization: Bearer <token>`.

## Use it

Paste a report link, or a number like `BB-123`, into the agent. It can:

- read the report: details, timeline, console, network, user actions, performance, the files and lines that failed, the screenshot, and comments;
- look at a recording frame by frame (see below);
- search reports;
- comment (shown with a **via AI** badge);
- change status, priority, or assignee;
- send the report to a tracker.

### Recordings

For a video report, the agent gets a link to the video that works for 5 minutes, and the moments worth looking at, in
video time:

- errors and failed requests;
- the click just before them;
- your notes, rage clicks, and page changes.

It also gets the `ffmpeg` commands that cut a frame at each moment. An agent that runs on your computer, such as
Claude Code, Cursor, or VS Code, downloads the video, cuts the frames, looks at them, and deletes them when it's done.
It needs [ffmpeg](https://ffmpeg.org/download.html) installed.

Apps that can't run commands, such as ChatGPT or Claude.ai, still get the recording's thumbnail.

### Let the agent record

A coding agent can also make recordings: it drives a browser, records the bug, and files the report. It can even test
a page by itself and file each bug it finds. See [Agent recordings](/guide/agent-recordings) and
[Testing a page](/guide/agent-recordings#testing-a-page).

## What an agent can't do

An agent can see and change exactly what you can in the dashboard, except that it can't delete reports, change who can see a report, or manage workspaces.

## Stop an app

The **AI Agents (MCP)** page lists the connected apps and your tokens. Revoking either stops it immediately.
