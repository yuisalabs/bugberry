---
title: Tracker integrations
description: Send a report to GitHub Issues, GitLab, Linear, Jira or ActiveCollab.
---

When a workspace admin has connected a project to a tracker (see [Integrations](/self-host/integrations) for setting it up), reports in that project can become issues or tasks. BugBerry works with GitHub Issues, GitLab, Linear, Jira Cloud and ActiveCollab.

- **By hand:** open the report, open its **More** menu, and choose **Send to GitHub · …**, **Send to Jira · …** and so on (the name after the dot is the integration's).
- **Automatically:** when the integration has auto-send on, every new report in the project is sent as soon as it finishes uploading.

The issue gets the report's title and description, a link back to the report, the page, the browser, the OS, the viewport, the number of console errors and failed requests, and the error messages. The reporter's city is never included.

Once sent, the report shows the issue the way the tracker names it: `#42` for GitHub, GitLab and ActiveCollab, and the key itself for Linear and Jira, such as `ENG-142` or `BUG-12`.

A report without a project can't be sent; add it to a project first, from its page. Moving a report into a project doesn't send it automatically, so send it from the **More** menu.

To have a chat channel hear about new reports instead, see [Notifications](/self-host/integrations#notifications).
