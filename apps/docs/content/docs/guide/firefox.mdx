---
title: BugBerry on Firefox
description: What works differently in the Firefox extension.
---

BugBerry works on Firefox 130 or newer, installed from Firefox Add-ons. Screenshots, reviewing, and sending work the same as on Chrome. Recording differs:

- **Firefox always asks which screen or window to share.** It can't record a single tab on its own, and it has no system audio. The microphone works; the camera bubble, which needs a tab recording, isn't offered.
- **A small BugBerry recorder window opens for each recording.** Keep it open while recording; minimizing it is fine. Closing it loses the recording.
- **Opening BugBerry is <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>B</kbd>**, because Firefox uses <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>K</kbd> for its Web Console. The other [shortcuts](/guide/recordings#shortcuts) are the same.
